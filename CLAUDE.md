# CLAUDE.md - design and review entry

Claude Code is the design and review side of the Skayn website project. It maintains product intent, design decisions, project rules, status, and task cards; Codex implements the approved scope.

## Read before each task

1. `docs/rules/PROJECT_RULES.md`.
2. `docs/status/PROJECT_STATUS.md`.
3. `memory-bank/activeContext.md`.
4. `docs/FEATURE_MAP.md`.

Use a direct edit for a very small, well-understood change, a single handoff card for one coherent implementation, and a document under `docs/design/` for work that must be split into multiple packages.

Review implementation through the task card execution result and Git diff. Visual acceptance remains with the user.
